O que outros geradores não fazem

3.1

Funciona em qualquer caixa de entrada

Gmail, Outlook, Apple Mail e celular. Layout em tabelas e botões em VML seguram o e-mail até no Outlook de desktop, onde a maioria dos geradores quebra.

3.2

Revisão antes de enviar

A ferramenta aponta o que falta: link de descadastro, texto alternativo nas imagens, botão sem destino, endereço inválido. Um clique leva ao campo.

3.3

Gmail, ESP ou arquivo

Copie o HTML para Mailchimp, RD Station ou Brevo, cole o e-mail pronto no Gmail ou baixe o .html. Variáveis como {{nome}} são mantidas.

3.4

Link curto que mede

Links de WhatsApp no seu próprio domínio, com contagem de cliques. Eles só levam ao WhatsApp, então não servem para golpe.

3.5

Salva sozinho, desfaz quando precisa

O trabalho fica guardado no navegador enquanto você edita. Trocou de modelo, de cor ou excluiu um bloco sem querer? Desfazer.

3.6

Seguro por padrão

Todo texto colado é limpo e todo link é validado. Nada do que você digita vira código executável no e-mail ou na página.

06

Perguntas frequentes

O e-mail funciona no Outlook?

Sim. O HTML usa tabelas e estilos inline, e os botões têm uma versão em VML só para o Outlook clássico, que usa o motor do Word e costuma quebrar e-mails de outros geradores.

Posso usar o HTML no meu ESP?

Sim. Copie o código e cole em Mailchimp, RD Station, Brevo, Salesforce ou qualquer ferramenta que aceite HTML. Variáveis como {{nome}} e o link de descadastro do seu ESP são mantidos.

Dá para enviar pelo Gmail sem ESP?

Dá. O botão “Copiar p/ Gmail” copia o e-mail já renderizado: é só colar no corpo de uma mensagem nova, com imagens, cores e botão.

Como funciona o link curto do WhatsApp?

O link fica no próprio domínio (emailgenerator.com.br/w/código), conta os cliques e só redireciona para o WhatsApp, nunca para outro site. Ele também vira QR Code.

Onde ficam os meus dados?

O e-mail que você monta fica salvo no seu próprio navegador. O único dado guardado no servidor é o número e a mensagem de um link curto de WhatsApp, quando você pede para encurtar.
